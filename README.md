# ¿Cuánto conocés a Meme? 🎂 (Edición Cumpleaños)

Web App interactiva y picante de trivia desarrollada en HTML5, Tailwind CSS y Vanilla JavaScript con diseño Mobile First.

## 🚀 Características
- **11 preguntas exclusivas** con fotos reales y anécdotas oficiales.
- **Microinteracciones y Audio:** Efectos sonoros sintetizados mediante Web Audio API y animación de confetti.
- **Respuestas Aleatorias:** Las opciones se barajan aleatoriamente en cada ronda para evitar copias entre invitados.
- **Podio y Persistencia Local:** Tabla de posiciones con medallas guardada en `localStorage`.
- **Integración con WhatsApp:** Envío de puntajes preformateados directo a Meme.

## 📱 Despliegue en GitHub Pages
Para habilitar la web app pública y jugarla desde cualquier celular:
1. En GitHub, ve a **Settings** > **Pages**.
2. En **Build and deployment** > **Source**, selecciona `Deploy from a branch`.
3. Selecciona la rama `main` y la carpeta `/(root)`, luego guarda.
4. En 1-2 minutos tu enlace estará disponible en:
   `https://martuugreco1104.github.io/cumple-meme/`
